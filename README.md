# YouMeal — доставка авторской кухни

Многостраничный сайт доставки еды по собственному макету в Figma.
Учебный проект для портфолио: **заказы не принимаются, данные никуда не отправляются** —
всё работает в браузере, состояние хранится в `localStorage`.

## Стек

- Vite 5 + React 18 + react-router-dom (`HashRouter` — на GitHub Pages прямые ссылки не дают 404)
- Без UI-библиотек и TypeScript
- CSS Modules + БЭМ внутри модулей; глобально только `src/styles/global.css` (сброс, шрифт, токены)
- Шрифт Inter (Google Fonts)
- Деплой на GitHub Pages через `gh-pages`

## Возможности

- **Главная** — первый экран с кнопкой «В меню», блоки «Недавно смотрели» (из истории просмотров; пока истории нет — «Рекомендуем попробовать»), «Новые блюда», «Популярные блюда».
- **Меню** — сетка блюд, чипсы категорий, сортировка (популярность, цена, калорийность), фильтры: основной ингредиент, особенности (вегетарианское, без глютена, без сахара, острое, низкокалорийное), поиск по названию, кнопка «Применить». На мобильной фильтры — выезжающая панель.
- **Блюдо** — галерея фото, описание, состав, время, пищевая ценность, цена, «В корзину» / счётчик, избранное, «К этому блюду подходят».
- **Корзина** — количество +/−, удаление, демо-промокод `SPRING2026` (−1 000 ₽ от 2 000 ₽), сумма; счётчик в шапке; понятное пустое состояние.
- **Оформление** — форма с проверкой полей, скидка 5 % за оплату онлайн, выбор интервала доставки. Отправка — демо: корзина очищается, заказ сохраняется как «прошлый», появляется окно «Заказ №… оформлен!».
- **«Повторить прошлый заказ»** в шапке — кладёт прошлый заказ в корзину; если заказов не было, кнопка бледная и показывает подсказку.
- **Избранное** (сердечки), **личный кабинет** (последний заказ), страница **«доставка»**.
- Доступность: семантическая разметка, `alt`, кнопки — `<button>`, модалки и панели держат фокус и закрываются по Escape.

## Запуск

```bash
npm install
npm run dev       # локальный сервер: http://localhost:5175/Food_project/
npm run build     # сборка в dist/
npm run deploy    # сборка и публикация на GitHub Pages
```

Vite 5 требует Node 18+.

## Адаптив

| Версия    | Ширина экрана | Макет   | Что меняется                                                              |
| --------- | ------------- | ------- | ------------------------------------------------------------------------- |
| Мобильная | до 599 px     | 320 px  | бургер-меню, карточки на главной листаются вбок, меню в одну колонку      |
| Планшет   | 600–1023 px   | —       | карточки сеткой на всю ширину (2–3 колонки), чипсы категорий, фильтр в панели |
| Лаптоп    | 1024–1399 px  | —       | меню в шапке, колонка фильтров, промежуточные размеры                     |
| Десктоп   | от 1400 px    | 1400 px | значения из макета; шире 1400 контент по центру                            |

Размеры задаются CSS-переменными в `global.css` и переопределяются медиазапросами.

## Структура

```
public/images/          фото блюд (dishes/), тарелка и пятно первого экрана, логотип, логотипы оплаты (payment/)
src/
  App.jsx               маршруты и общий каркас (шапка, подвал)
  store/StoreContext    корзина, избранное, история, прошлый заказ, промокод (localStorage)
  data/                 блюда, категории, фильтры, навигация, тексты, доставка, оформление
  pages/                HomePage, MenuPage, DishPage, CartPage, CheckoutPage, DeliveryPage,
                        FavoritesPage, ProfilePage, NotFoundPage
  components/           каждый компонент — папка с <Имя>.jsx и <Имя>.module.css
    Header, MobileNav, Footer, Hero, Container            — каркас
    DishCard, DishList, DishSection, Badge, Price,
    QuantityControl, FavoriteButton, Gallery              — блюда
    FilterPanel, CategoryChips, SortSelect, Drawer        — меню
    CartItem, CartSummary, OrderSummary, CheckoutForm,
    OrderSuccess, RepeatOrderButton                       — корзина и заказ
    Button, Checkbox, Radio, FormField, Modal, Icon,
    SectionTitle, EmptyState                              — UI Kit
  hooks/                useLocalStorage, useDialog (фокус, Escape, блокировка прокрутки), useMediaQuery
  utils/                asset, cx, format, menu (фильтры и сортировка), order (суммы, интервалы), validate
  styles/global.css     сброс, шрифт, токены версий
```
